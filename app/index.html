6-Week Implementation Roadmap
Week 1: On-site RF Survey, metallic interference check & floor plan digitization
Week 2–3: Gate Portal & Zone Antenna mounting, PoE+ switch cabling
Week 4: Software installation, Employee DB import & RFID card encoding

Key Technical & Compliance Assurances
✅ Offline Buffering: Edge readers buffer scans if LAN drops — zero lost punches.
✅ Anti-Bounce Arbitration: RSSI hysteresis eliminates false zone hopping.
✅ GDPR & Role Access: Role-based views (Admin, Supervisor, HR, Security).
✅ ERP / Payroll Ready: Automated CSV / REST API attendance exports.
✅ Scalable: Add new halls, antennas, or cards anytime without re-architecting.
